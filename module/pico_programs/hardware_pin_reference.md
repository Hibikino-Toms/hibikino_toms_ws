# Pico 2 W ハードウェア・ピン設定

今後のプログラム作成用に、現在の配線とソフトウェア設定をまとめる。
対象ボードは Raspberry Pi Pico 2 W（PlatformIO: `rpipico2w`、Arduino framework）。

2026-11-12に実配線を確認済み: サーボGP17、NCリミットGP19。
M1はロール、M2は直動です。実動作確認で以前のM2方向想定が逆と判明したため、自動収穫用ファームウェアは論理正PWMをGP13、論理負PWMをGP12へ出力します。論理正が引込み、論理負が押出しです。診断用の`motor_sensor_test_20261111.ino`はGP12/13を直接駆動するため、その生PWM符号と論理方向を混同しないでください。
現在のPicoファームウェアと自動運転YAMLは、フックサーボを1500µsで停止、1600µsで閉方向、1350µsで開方向に設定します。値の大小が中立値を挟んで逆順のため、端点クランプは数値の最小値・最大値で行います。

## 現在使用するピン

| 機器 | 信号 | Pico 2 W | 設定・用途 |
|---|---|---:|---|
| モーター1 / TC78H653FTG | IN1 | GP10 | 正転・逆転用PWM |
| モーター1 / TC78H653FTG | IN2 | GP11 | 正転・逆転用PWM |
| モーター2 / TC78H653FTG | IN1 | GP12 | 正転・逆転用PWM |
| モーター2 / TC78H653FTG | IN2 | GP13 | 正転・逆転用PWM |
| ポテンショメータ1 | C（ワイパー） | GP26 / ADC0 | 12-bit analogRead |
| エンコーダー4（モーター2の回転検出） | A | GP8 | `INPUT_PULLUP`、CHANGE割り込み |
| エンコーダー4（モーター2の回転検出） | B | GP9 | `INPUT_PULLUP`、CHANGE割り込み |
| FB5311M-360 | 制御信号 | GP17 | 50 Hz PWM |
| FB5311M-360 | フィードバック | GP28 / ADC2 | 12-bit analogRead |
| NCリミットスイッチ | COM/NC接点 | GP19 | `INPUT_PULLUP`、開放で引込み停止 |

### センサーの接続

- ポテンショメータ1: A端子を3V3、B端子をAGND、C端子をGP26へ接続する。
- EC12エンコーダー4: AをGP8、BをGP9、共通端子CをGNDへ接続する。内部プルアップを使用する。
- FB5311M-360: FB線をGP28へ接続する。FB出力は0～3.3 Vの範囲で使用する。
- GP26/GP28を含むADC入力には3.3 Vを超える電圧を加えない。

### リミットスイッチ

- GP19とGNDの間にNC接点（COMとNC）を接続する。
- 通常時（接点閉）はLOW、作動または配線断線時（接点開）はHIGH。
- テストプログラムではHIGHを検出するとモーター・サーボを停止する。
- 自動収穫用の新ファームウェアでは原点復帰中は直動以外を停止し、HIGHで直動を即停止、40msの安定検出後にENC4を0にする。初期HIGHは断線とも区別できないため、制限付きで離脱してLOWと最低1カウントの移動を確認してから再引込みする。

## 電源とドライバー

- 小型DCモーター: GA12-N20、3 V・50 RPM仕様。モーター電源はTC78H653FTGのVMへ3.0 Vを供給する。
- TC78H653FTG: 1枚で2モーターを使用する設定。LARGE=GND、MODE=GND、STBY=3.3 V。
- モーター電源のGND、PicoのGND、サーボ電源のGNDを共通にする。モーター電流の戻り道をPicoのAGND配線に通さない。
- Picoの3V3端子からモーターやサーボへ給電しない。
- FB5311M-360は別電源で4.8～6 Vを供給する。サーボ電源は停止時だけでなく負荷時の電流にも余裕を持たせる。
- TC78H653FTGのVM-GND間にはセラミック0.1 µFをICの近くに配置する。電源入力付近に電解100 µFを追加する場合は、＋をVM、－をGNDへ接続する。現在確認された電解コンデンサは25 V・100 µF。

## 信号・プログラム設定

- ADC読み取りは12-bit（0～4095）。電圧換算は概算で `raw × 3.3 / 4095`。
- モーターPWMは0～255、20 kHz。`motor_sensor_test_20261111.ino`の実際の定数はPWM 200（約78%）。自動原点復帰はYAMLで設定し、初期値は140。
- FB5311M-360は連続回転型。制御パルス1500 µsで停止、1600 µsと1400 µsで方向別テストを行う。信号周期は20 ms（50 Hz）。
- FB5311M-360のフィードバックは軸位置に応じた0～3.3 V。停止パルス中でも軸が動けばFB値は変わる。
- シリアルモニターは115200 bps。現在のテストプログラムは`s`で開始、`x`で中止する。

## 未使用・旧割り当て

- モーター3（GP14/GP15）とモーター4（GP16/GP17）のDC駆動は現在未使用。GP17はサーボ制御信号に再割り当て済み。旧4DC用ファームウェアをこの配線で使用しない。
- ポテンショメータ2（GP27）は未使用。旧ポテンショメータ3のGP28はサーボFB入力に再割り当て済み。
- エンコーダー4をGP8/GP9につなぎ、現在はモーター2の回転検出に使う。旧エンコーダー1～3のGP2～GP7は未使用。
